# YouTube Playlist Downloader (Electron)

تطبيق سطح مكتب مبني بـ Electron.js لتحميل قوائم تشغيل يوتيوب بالكامل (فيديو MP4 أو صوت MP3).

## الميزات
- تحميل قائمة تشغيل كاملة من رابط واحد
- اختيار النوع: فيديو أو صوت
- اختيار جودة الفيديو (1080/720/480/360/أفضل جودة)
- تحديد مجلد الحفظ وعرض تقدم التحميل
- الواجهة بالعربية واتجاه RTL

## المتطلبات
- [Node.js](https://nodejs.org/) (v18+)
- اتصال بالإنترنت (يتم تنزيل yt-dlp تلقائياً عبر `youtube-dl-exec`)

## التثبيت والتشغيل
```bash
npm install
npm start
```

## الاستخدام
1. الصق رابط قائمة التشغيل في الحقل العلوي.
2. اختر النوع (فيديو/صوت) والجودة.
3. اضغط «تصفّح» واختر مجلد الحفظ.
4. اضغط «عرض القائمة» ثم «بدء التحميل».

## البناء (Windows exe)
```bash
npm install
npm run dist
```

## ملاحظات قانونية
هذا البرنامج للأغراض التعليمية. احترم حقوق النشر وشروط خدمة يوتيوب，
ولا تستخدمه لتحميل محتوى محميّ دون إذن.
